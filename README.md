📖 Overview

This project is a blog website that allows users to read articles and post comments interactively. It is designed to be clean, responsive, and user-friendly, focusing on the front-end implementation using HTML, CSS, and JavaScript.

✨ Features

✅ Responsive blog layout (works on all devices)
✅ Interactive comment section (add & display comments instantly)
✅ Clean and modern UI design
✅ Organized structure for multiple blog posts
✅ Uses local storage to save comments (no backend required)

🛠️ Technologies Used
Technology	Purpose
HTML5	Structure and content of the website
CSS3	Styling and responsive design
JavaScript (ES6)	Interactivity and dynamic features
📁 Project Structure
blog-website/
│
├── index.html          # Main HTML file
├── style.css           # Stylesheet for layout and design
├── script.js           # Handles comment logic and interactivity
└── assets/             # Folder for images or icons

⚙️ How It Works

Open the index.html file in your browser.

Browse the blog posts available on the homepage.

Scroll down to the comment section.

Enter your name and comment, then click Submit.

Your comment will appear instantly below the post.
